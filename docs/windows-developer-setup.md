# Windows 11 Developer Environment Setup

## Core Tooling Stack
1. **PowerShell 7 (`pwsh`):** Core scripting runtime.
2. **Starship Prompt:** Fast cross-shell prompt with sub-10ms render latency.
3. **Rustup:** Native `x86_64-pc-windows-msvc` toolchain with MSVC C++ Build Tools.
4. **Git for Windows:** Configured with `core.autocrlf = true` and OpenSSH credential manager.
